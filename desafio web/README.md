> Aplicación web interactiva que aplica la **serie de Fibonacci** y los **números primos** a problemas del mundo real.

## 📌 Descripción

La página permite al usuario:
- ✅ Calcular ahorro progresivo usando Fibonacci
- ✅ Verificar si un número es primo
- ✅ Generar Fibonacci y detectar primos automáticamente

## 🎯 Problemas del mundo real

| Modo | Aplicación |
|------|------------|
| 💰 Ahorro Fibonacci | Plan de ahorro personal |
| 🔐 Números primos | Seguridad informática |
| 🌀 Fibonacci + Primos | Análisis matemático |

## 🚀 Tecnologías

- HTML5
- CSS3 (Glassmorphism, Responsive)
- JavaScript ES6
- Font Awesome 6
